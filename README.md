# GrowthNest

GrowthNest is a mentor dashboard for managing courses, students, sessions,
tasks, messages, content, and analytics.

## Project Structure

```text
GrowthNest/
└── frontend/   React and Vite application
```

## Run Locally

```bash
cd frontend
npm install
npm run dev
```

## Available Checks

```bash
cd frontend
npm run lint
npm run build
```
